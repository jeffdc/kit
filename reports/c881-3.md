## What was built

### Summary

Reworked after your reviews. Every open question, review and decision is marked on the row that holds it, and the counts add up: each entry is counted once, item rows carry their own, items with no phase sit under 'No phase', entries not on an item under 'About the plan' or 'About the project', and each row's count is the sum of what's below it. Every mark opens that sheet at its Needs you with its tiers open. The mark is your pick from three rendered options: an ink box with a 3px muted violet left edge, beside the yellow blocking stamp. Clouds are calmer: changed things next to each other share one cloud (Needs you tiers and decision groups too), an open decision group no longer clouds itself as well as its rows, and a multi-line clouded title is clouded as one block. A sent-back review reads 'sent back', not 'do'. The superseded decisions (192e, 53c1, d4a3) are dropped.

### UI tour

1. Run make install in mull/, restart mull serve, open http://localhost:6855/.
2. Sheet index: each project shows a yellow 'N BLOCKING' for blocked work and an ink-boxed 'N FOR YOU' with a violet left edge for the rest; plans, phases and items carry the same boxes, and each row's count is the sum of the rows below it.
3. Click any box: that sheet opens scrolled to its Needs you, every tier open.
4. Open c881's item sheet: its long title sits inside one cloud; open the decisions: the changed rows share one cloud, and the group itself isn't clouded around them.
5. On a project overview with several new questions next to each other in a tier, they share one cloud.
6. Dark mode: the box is light ink with a lighter violet edge.

### Design notes

Since report 2 (counts, item rows, No phase and About rows, linked marks), three changes, all in the UI.

The mark: the filled violet was garish. Impeccable's quieter lens put it down to a block of saturated screen violet with white type, a UI-kit badge among pencil and ink marks. Three alternatives were rendered on the real sheet index, light and dark; the human chose an ink box with a 3px inset violet left edge (#5B3F98, #B6A2EC dark). .ask and a closed tier's count use it; --vi-ink is gone. It's the second sanctioned left stripe in DESIGN.md, by the human's choice.

Clouds: runs(parts, cloud, plain) in revision.js joins consecutive changed pieces under one wrapper, as the sheet index already did for its rows and joinRowClouds for table rows. Needs you rows now return [html, cls] and a tier wraps runs in a .clrun div; a decision group's list becomes ul segments, changed runs in ul.clrun. An open group's own cloud is hidden by CSS (.grp[open].cl), so the group carries the cloud only while closed. The title block's clouded name is inline-block, so its cloud wraps every line.

Settlements read as taken: a SETTLED map turns do into 'sent back', decide into 'decided', and so on, on the review state and on carried decisions.

Rejected: dropping clouds from decision rows altogether (a new decision must still read as new); a cloud on every changed row with tighter insets (still a cloud per row).

Checked in Brave on c881's sheet and the fixture overview: one cloud per run, the title inside its cloud, no console errors.
