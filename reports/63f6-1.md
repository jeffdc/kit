## What was built

### Summary

Not on mull yet is gone from mull serve, as Jeff asked. The server no longer scans the directories beside the registered repos (GET /api/unmulled, its scanner and its tests are removed), and the page no longer fetches it. The rail's footer holds only the link to The model: how mull works; its Needs converting, Not on mull yet and Can't read groups are gone. All projects drops its Not on mull yet field and grouped rows, and still lists registered repos that can't be read as rows under its table (errorRow), each saying what to do. The bench's unmulled scan target and the docs (design.md, serve/DESIGN.md's Shell, the json guide, the README) follow.

### UI tour

1. Open All projects (#/): the title block has Projects on mull, Blocking, Needs you, Agents working and Status, and no Not on mull yet field.
2. Look at the bottom of the left rail: only the button The model: how mull works, on any sheet.
3. Register a path that isn't a repo (or a repo with no mull branch) and reopen All projects: it's a row under the table saying why it can't be read, with no Can't read group in the rail.
4. Click The model: how mull works: the button shows as current on the model page.
5. At phone width open Sheet index: the tree, then only the model button.

### Checks (run by mull)

- `make done-checks`: pass, 6.2s

## How it was built

### Design notes

Removed rather than hidden: the endpoint, its scanner, the client fetch and every place that drew its results go together, so nothing scans directories Jeff's registry doesn't name.

notOnMull went entirely rather than being reduced. Its only remaining job was the list of registered repos that can't be read, and that's now a one-line filter in pageHome (all.filter(p => p.error)); the old exclusion of paths the scan had also listed no longer has anything to exclude. loadList fetches only the project list, with a try/catch in place of Promise.allSettled.

The rail footer's Can't read group went too, as the item says: All projects still shows those repos with errorRow, so nothing is lost. The empty state is unchanged (No projects yet...), which now only depends on there being no registered repos.

CSS: only .rail-foot p was used by the removed groups (the names under each label), so it went; .rail-foot and its .btn.on stay for the model link. The grp-h and waits row styles stay, since other tables use them. pages.js no longer imports ago.

docs/serve/prototype.html still shows a Not on mull yet field and rows. It's the approved prototype, a record of the design as proposed, so I left it as it was.

Verified with make test, make vet and make fmt-check, and in make dev on port 6904 with a headless Chromium: the rail footer's HTML is only the model link, GET /api/unmulled is 404, and a registered path that isn't a repo shows as an errorRow (not_a_repo) under All projects, at desktop and phone width.
