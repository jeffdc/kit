## How it was built

### Design notes

Edited the existing guides in place rather than rewriting them: 2b8f, 462a, 5ea9, 2f34 and 0455 had already moved much of the wording to Model v2 (bug not loose, --plan none, design notes, plan agree, triage), so the work was filling the remaining gaps and keeping each guide's voice and length, since they are pasted into other projects' AGENTS.md.

agents.md: a one-line "The record" bullet gives the stages and what captured means; step 1 reads the item's docs and phase_doc (intent only); step 2 says a captured item is started only when the human hands it over; step 3 settles the capture rule (anyone captures, only the human commits; agents may file their own ideas, decision 33a6), says the backlog is not Needs you and points at mull guide triage; step 4 covers plans and phase docs, shaping plans, needs only between phases, and retagging only on the human's word; step 5 says done means reviewed. The human-feedback block is unchanged, so the existing cmd test still holds. AGENTS.md's block is a byte copy of agents.md (the epics/phases drift is gone); its top part adds mull-serve and a note on the legacy general plan.

supervisor.md: reads plan and phase docs before starting, ready now says agreed plans, a new Backlog section (triage guide, commit, set plan/phase, drop, and the legacy loose ends/ideas until migrate), Needs you named as questions, decisions and reviews, and the accept step states 86db explicitly (ratifies with or without --on-request, so the human's say-so comes first).

intake.md: a step 0 for repos that already have a mull branch (migrate --dry-run with the human, then migrate, then skip init), plan and phase docs proposed from hub documents with no status in them, plan doc and phase doc lines in the example batch (refs resolve on slug and id), step 5 renamed to Needs you and the backlog, categories on old-backlog captures. Only --dry-run is named for migrate, to avoid depending on 488d's other flags.

triage.md: one line on legacy loose ends and inbox ideas pointing at migrate, and a caveat that start can't commit into a shaping plan.

context.go protocol lines follow the guide. README gains plan states, docs and stages; mull/CLAUDE.md and the root CLAUDE.md drop epics and loose ends.

Tests: rather than test every sentence, cmd_test checks a few load-bearing phrases per guide, and a new test runs the intake guide's example batch as written in a temp repo, since that block is what intake agents copy and it now includes the doc ops. Rejected: a test comparing kit's AGENTS.md with agents.md from inside mull's tests, which would tie the mull tool's tests to one repo (filed as idea 3ca8 instead).
