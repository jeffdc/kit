## How it was built

### Design notes

The icon is a hand-drawn SVG (web/favicon.svg) rather than text in Archivo: a favicon can't load the page's web font, so the m is three stroked paths (a left stem and two arches) with flat ends to look like type. It's built on a 32-unit grid with 3.6-unit strokes, which still reads as an m at 16px (checked by rendering with rsvg-convert). The tile uses --blue (#2E58C2), which stands out on both light and dark tab strips, so it has no dark variant. It's served through the existing embedded FileServer, so nothing changed on the Go side; the static-file test now checks /favicon.svg too. I left out the option of a live inbox dot (Jeff picked the plain icon).
