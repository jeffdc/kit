## What was built

### Summary

The human's name is now per machine, as Jeff decided on 74d3: mull name <name> keeps it in ~/.config/mull/name ("" clears it), never on the mull branch, so each person on a repo has their own. The repository config key is removed (kit's cleared). Guides print as written, since they're copied into shared files; kit's AGENTS.md is back to the neutral guide. The name reaches agents through mull context, which opens with the rule to write it, and through mull's messages and errors. This machine is set to Jeff.

## How it was built

### Design notes

internal/human keeps the name in a one-line file beside the registry (Name, SetName; empty removes the file, and a multi-line name is refused). The config directory moves to internal/confdir, which imports nothing of mull's, because human importing registry made a cycle through registry's tests; registry.Dir now delegates to it.

mull.Human() reads the machine's name, so Context's protocol (rule first, every line personalized) and m.personal (done's reminder, start's warning) follow the machine. cmd.Execute personalizes errors from human.Name() directly, so it works outside a repository too. model.Config loses human, and config set refuses it again.

Guides: mull guide no longer personalizes. It's meant for AGENTS.md (its own help says so), and AGENTS.md is shared, which is the same leak as a repo-level name. guide.For is removed; Personal and NameRule stay for the context and messages. Every agent runs mull context first, so the rule still reaches them.

A new command rather than mull config set human: mull config is the repository's config on the mull branch, and a per-machine value under it would read as shared. mull name prints {name, file} (documented in mull guide json).

Tests: human.TestName (set, trim, refuse two lines, clear); cmd.TestHumanName (name shown and set; guide byte-identical with a name; repo config untouched; context protocol opens with the rule and never says the human; an error says only Jeff creates a plan; clearing restores both).
