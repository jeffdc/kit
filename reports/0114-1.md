## What was built

### Summary

mull serve now self-hosts its fonts and has its design written down. Archivo (variable width and weight) and Red Hat Mono are embedded as woff2 (latin, latin-ext) with their OFL licences and a provenance README, declared with @font-face and preloaded: the page makes no outside requests. The impeccable finish review ran on the real build at 1440, 1280, 900 and 400 px, light and dark, against direction.md and the prototype: verdict ship after fixes, and its fixes are in (tabs keep their height and put actions on their own row from 1180px down; the current sheet-index row stays blue; no raw not_initialized code; tables fit phone width with clouds closed). DESIGN.md (with a design.json sidecar) records the design system as built, in docs/serve, and mull's CLAUDE.md points to it. The model page the review found missing is now item bfcf; the human kept the current-row blue bar.

### UI tour

1. Run make build && ./mull serve and open http://localhost:6855/.
2. The type is Archivo (wide heavy names, condensed caps labels) and Red Hat Mono for IDs and figures. In the browser's network panel, every request goes to localhost: the fonts come from /fonts/.
3. Narrow the window to about 1100px on a project: Mark revision seen and Capture drop to their own row under the tabs, and a clouded Backlog tab's cloud sits around its label.
4. Open an item that's done (kit → mull serve → UI → e3f5): its row in the sheet index is blue and bold, with the blue bar at its left edge.
5. Narrow to phone width (about 400px) on All projects, a project's Backlog and a plan's Status: each table fits without scrolling sideways, and clouded rows are closed on the right.
6. On All projects, a repo without a mull branch reads 'No mull branch yet: run mull init in it to start.' with no code.
7. Read mull/docs/serve/DESIGN.md: the tokens, type, layout, components, the cloud system and the rules for changing the UI.

## How it was built

### Design notes

Fonts: the variable woff2 builds Google Fonts serves (Archivo wdth 62–125 wght 100–900, Red Hat Mono wght 300–700), fetched once and vendored under web/fonts with the OFL licences and a README recording the source, versions and date. Only latin and latin-ext: one file per subset covers every width and weight the CSS uses (~210 KB total), and glyphs outside them fall back to the system faces already in --font and --mono. @font-face rules copy Google's unicode ranges; font-display swap; the two latin files are preloaded from index.html. TestEmbeddedReferences now checks every module import, stylesheet url() and page href/src names an embedded file, and that fonts are served as font/woff2.

Finish review: run with impeccable's finish reviewer, which reviews only from captures, so a capture script (headless Brave, full page, waitUntil load then document.fonts.ready, emulated dark, never clicking Mark revision seen) produced 45 shots of the build and the prototype at 1440, 1280, 900 and 400.
