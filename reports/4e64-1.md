## How it was built

### Design notes

AsHuman (internal/mull/mull.go) is the one place a page write gets its name, so the change is there: it reads humanname.Name() (mull name, ~/.config/mull/name) first and falls back to git config user.name. Everything downstream (Settled.By on entries, the "<name> in mull serve" source on captures, "Dropped by <name>" on dropped captured items) already used m.human, so nothing else changed. Reading the per-machine name inside internal/mull is consistent with mull's own messages, which already use it (guide.Personal). The refusal message now names mull name first. Tests: TestAsHumanPrefersMullName covers git name only, both set, and mull name only; TestAsHumanNeedsAName now expects the mull name hint. Tests are isolated from the real config dir through gittest's XDG_CONFIG_HOME. Docs: design.md and the JSON guide say where the name comes from, and the guide's list of ops the page may write is brought up to date (bug, idea, set, plan agree, plan close, plan doc, phase doc had been added without updating it).
