## How it was built

### Design notes

How: Makefile targets plus scripts/dev-demo.sh. dev depends on build, dev-demo and dev-stop, then starts ./mull serve --port DEV_PORT (6899) from .dev/demo with XDG_CONFIG_HOME=.dev/cfg, records its PID in .dev/serve.pid (the braces matter: without them the & backgrounds the cd as well and $! is a subshell's), and waits for /api/build to answer. dev-stop kills only the PID in that file and waits for it to exit. dev-demo runs the script once: a git repo with mull init, checks set to true, an agreed plan with a doc, a ready item with a question (Blocking), decisions from an item and from a planning call (Decisions), an item through mull done carrying two decisions (Review and a packet), a long-titled item and a captured bug. dev-reset removes .dev and starts again. The permission check sees make dev, not the kill inside it, so the human keeps their pkill ask rule. Checked: make dev serves the demo (blocking 1, review 1, decide 5; the registry holds only the demo), a second make dev replaces the first server, make dev-stop leaves nothing on 6899.
