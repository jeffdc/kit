mull serve keeps the parsed state of each repository in memory, keyed by the mull ref's commit, with lookups by plan, phase and state built once per commit. A request whose ref hasn't moved costs one rev-parse. Project summaries and the unmulled scan are computed once and reused until something they read changes (the watcher already knows when). The LaunchAgent stops running as Background (fa47).

Done when the benchmark shows pages well under 100ms on the large repository from the installed server, and correctness holds: a write is visible on the next request.
