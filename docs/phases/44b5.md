# Rank in mull serve

## Design

mull serve's item tables (a phase's sheet, a plan's no-phase items, Unplanned), the Plans column and the ready lists follow rank as the CLI does: open work in rank order, done and dropped after it.

Open, to settle in the item with Jeff: whether a table shows rank as position only, or a small position number (1, 2, 3, equal ranks sharing one) on open items.

## Done when

A phase's sheet lists its items in the order `mull rank` gave, and changes to the order are clouded like any other change.
