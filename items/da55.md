2. (60c3) mull worktrees lists `git branch -d` for the item's branch before the branch it tracks (the harness's worktree-agent-… branch), so -d refuses with "not yet merged to its upstream". 3. (50aa) mull serve's revision schedule links a plan_doc or plan_rules change to the plan's Status tab, not its Plan doc tab where the change is.
4. (dc0f) context --item hands the worker its plan's shared globs, beside target and preview, so workers know which files are shared before they touch one.
