A plan field preview (mull plan set <slug> preview <url>): the URL that serves the plan's target branch. mull context --item gives the worker the target and the preview. mull records it and never runs or checks the server.

Update docs/design.md, the guides (internal/guide) and mull guide json wherever behaviour or output changes. The plan's doc (mull plan doc supervised-work) has the whole picture and what stays out of mull.
