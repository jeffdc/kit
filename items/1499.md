mull worktrees: a read-only list of claim worktrees with their item, state and disk size. Prunable means the item is done, its work is in the target, and the worktree is clean; the list gives the git worktree remove and git branch -d commands for each. The view and mull serve show the prunable count and size as a problem. Never runs the removal.

Update docs/design.md, the guides (internal/guide) and mull guide json wherever behaviour or output changes. The plan's doc (mull plan doc supervised-work) has the whole picture and what stays out of mull.
